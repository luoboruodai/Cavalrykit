# CavalryKit 0.1.1 · UI / 可用性复查

本记录是工程启发式复查，不是第三方认证，也不替代真实用户测试。参考 Nielsen Norman Group 的 Ten Usability Heuristics；以用户提供的 Cavalry 深灰/绿色界面及 4/8/16/24 间距规则为视觉方向。

## 尼尔森原则逐项检查

| 原则 | 本版处理 | 证据 / 边界 |
|---|---|---|
| 状态可见 | 标题同行运行状态、后台步骤文案、队列/冲突数量、独立结果、设置保存状态 | UI 及后台事件测试；进程状态每 5 秒检查，不宣称实时 |
| 贴近用户语言 | 四语言界面、原始文件名不变、明确「覆盖/跳过/稍后」 | 124 个界面消息，占位符及所有界面字形检查；底层技术诊断保留原文 |
| 用户控制 | 取消本批、Esc 退出、设置预览可撤销、重启可稍后或停止等待 | 无强制终止 API；操作已写入时不会假称能够撤销 |
| 一致性 | 弹窗按钮组右对齐、相同按钮高度、字体/配色/布局 token | 四语言 × 深/浅主题 × 三档窗口尺寸的几何断言 |
| 错误预防 | 冲突必询问、覆盖暂存回滚、卸载必确认、重启前保存警告、参数预检 | 重复同名、自身导入、递归目标、压缩穿越、锁文件失败路径测试 |
| 减少记忆负担 | 可见导航文字、设置分组、显式筛选、搜索清除、帮助提示 | 图标旁保留文字；不靠颜色单独表示成功/失败 |
| 效率与灵活性 | 批次冲突选择、快捷键、虚拟列表、搜索缓存、偏好持久化 | 万条库与大结果列表限制渲染量；处理真实巨型输入仍受 I/O 限制 |
| 简洁聚焦 | 合并底部工具入口、详情默认折叠、失败原因可展开、有限设置项 | 不添加无关云服务/账户/更新推送 |
| 错误恢复 | 分开显示成功/跳过/失败，取消冲突仍保留早先失败，提供通用建议与技术详情 | 文件恢复副本与废纸篓提示；不提供未经验证的一键“万能修复” |
| 帮助与文档 | About、操作提示、双语 README、安装/恢复和显卡兼容说明 | 进程检测、平台限制、未签名状态如实说明 |

## 尺寸与间距

- 4pt：小文字或图标的紧密关系；8pt：同组元素与按钮之间。
- 16pt：主卡片/列表内边距；24pt：主区域间距、模态框内边距、设置分组间距。
- 主要控件 36pt，导入主按钮 40pt，列表行 56pt；保留原生窗口边框。
- 模态框正文宽度和最大高度受窗口约束，长文本滚动；动作按钮固定在底部。
- 界面缩放 90/100/110/125%，并用 100/125/150/200% DPI 输入验证可触达区域；不是实际多显示器交互验收。
- 标题、状态不重叠且同基线；左右区域不越界。搜索清除图标的独立 padding 避免推宽整个列表卡片。
- 自定义极端配色下正文/次要文字/状态文字采用至少 4.5:1 的对比度检查；强调按钮文字自动取黑/白。滚动条使用前景色，键盘焦点有可见描边。

## 已修复的本轮复查问题

1. `with_layout` 继承旧高度使小窗口设置弹窗超出边界：固定高度动作行，正文独立滚动。
2. 自定义中灰背景的文字颜色可能跨过对比度安全范围：对所有实际表面共同计算可读颜色。
3. 搜索清除按钮的 padding 大于预留槽，右边框被裁掉：为图标按钮使用独立 padding，并新增整个列表卡片边界断言。
4. 不同语言行操作占用不同宽度：按实际文本测量动作区，避免名称和操作重叠。
5. 取消冲突批次曾丢弃前面已发现的失败信息：保留并在结果中展示。
6. 原生系统主题事件曾覆盖部分控件的自定义配色：显式选择 egui 主题样式表，回归测试跨系统深/浅主题事件。
7. 下拉选择项曾保留白色字而忽略选中前景色：移除全局文字覆盖；选择项目后立即收起下拉菜单。

## 不应夸大的内容

- 自动布局/字形检查不是专业母语校对；翻译可继续根据使用反馈优化。
- UI 截图为程序真实渲染的合成库，不能把它们说成 Windows 实机截图。
- 没有运行用户 Cavalry 的真实关闭/重启测试，防止丢失未保存工作；原生平台代码完成构建，状态机分支用 fake backend 测试。
- Windows 用户实机体验验收延期，本版以已完成的代码、自动测试和静态产物检查交付。
