# CavalryKit 0.1.1 / build 14 · 后一轮参考要求对照

本轮按用户补充的具体要求验收，而不是沿用 build12/13 的旧视觉结论。保留左导入/右库布局、文件安全流程与原始图标，不因风格修改危险操作的确认规则。

## 逐项实现

| 区域 | 实现 | 交互 / 边界 |
|---|---|---|
| 列表卡片 | 休息态内缩8pt；hover/选中时平滑展开，左侧边条2→4pt、细描边和抬升底色；脚本绿/插件蓝。 | 整行只选择；命中区和菜单不位移，保留虚拟化与截断补全文案。 |
| 行右侧 | 一个40pt三点按钮，菜单内显示/卸载分组，危险动作红色。 | 鼠标/键盘可达，Esc/外点关闭；卸载仅打开确认。模态/忙碌状态关闭后台行菜单。 |
| 列表切换 | 全部/脚本/插件切换时，整张卡片依次从下方14pt上移并淡入，最长约700ms。 | 不是仅移动文字；固定全局序号防滚动重排，未显现的操作不可触发；减少动效立即到位。 |
| 搜索 | 图标、输入字形和44pt容器垂直居中，灰色提示，hover绿图标/1pt描边/浅绿底；焦点1.5pt。 | 使用TextEdit实际字形几何验证；点击图标/留白聚焦，清除单独热区；不随插件筛选变成蓝色。 |
| 搜索提示 | 四语16条，默认提示20秒、短提示4秒，切换用240ms淡入/淡出和轻位移。 | 默认超过80%；聚焦/输入/失焦/模态/减少动效不轮换。只在短过渡请求连续帧，静止时长延时唤醒，不污染查询值或可访问名称。 |
| 刷新 | 同搜索高44pt的常态底板，hover绿底/描边，按下反馈和380ms有限旋转。 | 不加入空闲spinner；后台扫描规则不变。 |
| 四个入口 | 单列等宽40pt卡片，四条边条/图标都使用绿色。 | 左侧入口不再把插件目录染蓝；库中插件类型色仍蓝。 |
| 导入/文字 | 中间灰表面区分侧栏；14pt主文案/11pt格式说明，提示弱化但保持可读。 | 卡片与独立44pt文件按钮不重叠；动作/说明4/8/16/24层级，导入hover仍为四边等宽，不添加粗左边。 |
| 品牌/状态 | 28pt品牌图、16pt标题与右侧小状态徽章同一行。 | 四语言/小窗口不重叠，状态文字保留“运行中/未运行”，原生窗口标题栏保留。 |
| 设置 | 14pt圆角模态、弱化说明；保存同文件动作的浅绿色底板+图标。 | 减少动效留在通用。表面先出现、正文后出现；退出反向；中途关闭从当前进度开始，重开重播而非跳终态。 |

参考的HUD只提炼“容器先展开、内容后出现、可取消收回”，不复制整段数秒HUD时间线，也不将源码分析冒称看完参考原生窗口动效。

## 尼尔森十项复查

| 原则 | 结论 | 本轮证据 / 边界 |
|---|---|---|
| 系统状态可见 | 自动范围通过，原生另记 | 状态同行徽章、筛选计数、忙碌反馈；不制造进度或常驻spinner。 |
| 用户语言/现实匹配 | 自动范围通过 | 四语提示/操作，原文件名不翻译；搜索提示不声称搜索文件内容。 |
| 用户控制与自由 | 自动范围通过 | 菜单Esc/外点关闭、设置取消恢复、减少动效；中途退出不跳动画。 |
| 一致性与标准 | 自动/静态通过 | 所有绿色入口、统一软填色主要动作，输入/刷新44pt同中心。 |
| 错误预防 | 自动范围通过 | 行选择不执行；菜单卸载仍确认，模态不遗留可点击的后台独立弹层。 |
| 识别优于回忆 | 已落实，菜单发现性待用户体验 | 常用入口有文字；三点具名称/提示，菜单显示动作名称，符合用户要求但比常驻动作多一次点击。 |
| 效率与灵活性 | 自动范围通过 | 缓存/虚拟化不变，文字轮换只在空闲启用，短动画结束停止逐帧请求。 |
| 美观与简约 | 逐项落实，审美待用户确认 | 参考的卡片外扩、字体层级/灰度、状态徽章、三点菜单和圆角；不称为像素级复刻。 |
| 错误诊断与恢复 | 原有回归通过 | 失败回滚与独立结果/技术详情不变；本轮不对真实库导入/卸载。 |
| 帮助与文档 | 已同步 | README/发布说明/合成截图与新菜单一致，真实截图和诊断不进入公开源码。 |
