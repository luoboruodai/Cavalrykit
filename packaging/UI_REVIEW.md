# CavalryKit 0.1.1 / build 16 · 行右侧协同与深浅材质一致性

本轮依据7张反馈图，保持用户认可的整体布局。**以深灰版的几何与信息层级为锚点**，调整明亮版材质，而非对所有页面做机械颜色反转。以下增量替代build15对应项；其余已确认要求继续保留。

## 尼尔森十项复查

| 原则 | 结论 / 证据边界 |
|---|---|
| 状态可见 | 徽章文字＋点、忙碌/结果提示保留；呼吸不替代状态文案，停止条件明确。 |
| 用户语言/现实匹配 | “程序位置”、主题名和动作与本轮术语一致；名称不改；混排字形不再随机依赖系统CJK。 |
| 用户控制 | 设置取消/恢复/减少动效保留，装饰不触发动作，未退出宿主测试。 |
| 一致性 | 搜索/刷新/列表边线统一；动作和设置复用token，深浅采用各自表面。 |
| 错误预防 | 显示/卸载热区分离、删除确认；模态背景动作不可点；未显现阶段不接受危险点击。 |
| 识别优于回忆 | 主要动作恢复常驻图标，有本地化名称/提示；三点没有误导的hover按钮/键盘目标。 |
| 效率 | 保留后台I/O、索引缓存、虚拟列表；呼吸只在有意义的前台运行态低频更新，其他动效有界。 |
| 美观与简约 | 逐项调整光学对齐、字体灰度、圆角、边条和留白；最终审美由用户判断，不声称像素级复制。 |
| 错误恢复 | 原有安装失败回滚、卸载确认/回收站与错误详情回归不变；未操作真实库内容。 |
| 文档与帮助 | 当前矩阵、README/说明/合成图同步；历史三点菜单说明标为被替代。 |
