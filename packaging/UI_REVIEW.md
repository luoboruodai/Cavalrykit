# CavalryKit 0.1.1 · build 7 UI 复查

工程启发式复查，不是第三方认证。此轮以用户明确的操作布局为准：**左侧导入，右侧列表顶部筛选与搜索**。不以“重设计”为由改变已明确的位置。

## 改动与保留

- 恢复左侧大拖入区；下方保留脚本目录、插件目录，关于与设置并排。
- 全部 / 脚本 / 插件回到右侧表单顶部；只显示一个当前结果计数。删除重复的库标题 / 副标题、侧栏分组名称、第二份版本信息和常驻策略页脚。危险操作的提示仍保留在发生操作时。
- 保留自有品牌与绿色强调色，只借鉴同类工具的中性色分层、细描边、规则圆角和有限缓动，不复制第三方素材、品牌或整套 HUD 动画。
- 浅色用白卡片 / 浅灰背景，深色独立分层；不再把深色调色算法直接反向用于浅色卡片。
- 按钮只绘制一层圆角外壳；hover / pressed 不扩大命中边界。小复选框使用 3pt 圆角，大按钮 8pt，卡片 12pt，避免小方框变圆点。目录 / 插件图标用连贯轮廓，所有矢量笔画都在槽位内。
- 约 140ms 的 hover / press / 筛选 / 拖入状态过渡。仅拖入装饰图标有 2pt 位移；不缩放列表、窗口或按钮点击区域，不使用持续波纹 / 弹跳 / 空闲动画。减少动效后立即切换。
- 后台 I/O、冲突安全默认、独立结果弹窗、设置草稿、可撤销预览、区域字体、平台应用图标及安装流程不变。

## 尼尔森十项逐项检查

“通过”只描述列明的工程测试与本机范围；剩余未验证条件见末尾。

|---|---|---|
| 系统状态可见 | 通过（已测范围） | 品牌栏文字状态；导入卡片显示后台阶段、队列 / 冲突数，独立结果与保存状态仍保留。多语言忙碌布局有断言。 |
| 符合用户语言与习惯 | 通过（已测范围） | 恢复用户指定的左导入 / 右筛选；搜索提示为「搜索插件或脚本名称」。四语言占位符、六字体子集和混排边界测试通过。未声称母语审校。 |
| 用户控制与自由 | 通过（已测范围） | 设置草稿与取消、Esc 取消、重启稍后、减少动效保留；关闭确认框不执行危险操作。状态机与键盘回归通过。 |
| 一致性与标准 | 通过（已测范围） | 统一按钮/图标/主题 token；点击壳体不随 hover 扩张，复选框保持小圆角，筛选等宽分段仅一个选中底板；模态底部动作右对齐。 |

| 识别优于回忆 | 通过（已测范围） | 原位置入口不变；类型筛选和搜索同属表单，图标动作有文字提示 / 无障碍标签；移除重复标题而不移除任务入口。 |
| 效率与灵活性 | 通过（自动范围） | 搜索缓存、万条虚拟列表、分页结果和快捷键保留。鼠标实际事件验证筛选；动画与稳态 hover 结束后不持续请求帧。不是 GPU / Windows 实机帧耗时结论。 |

| 帮助与文档 | 通过（文档 / 组件检查） | 导入格式、必要安全提示、About、双语说明及平台限制保留；README / 产品说明 / 更新日志与新布局同步。 |

## 间距、可读性与实际绘制

- 4pt 紧密关系，8pt 同组，16pt 卡片内边距，24pt 两列/明确分组；窄逻辑窗口两列间隔缩为16pt。圆角、字号和笔画独立于间距规则。
- 顶栏56pt、按钮36pt、搜索40pt、列表行64pt；导入高度根据剩余空间调整。文字真实排版尺寸用于放置提示和按钮，不裁掉文案腾位置。
- 四语言 × 深 / 浅 / 自定义 × 720×496 / 900×620 / 1120×760，含忙碌状态；断言导入/说明/按钮/图案都在左列，3个筛选、搜索、列表都在右列，底部入口可达。
- 四设置页、长模态、90/100/110/125% 界面缩放，以及100/125/150/200%模拟DPI的动作可达测试。默认原生窗口1120×760，最小900×620。
- 文本跨实际表面至少4.5:1；主按钮实际 hover / pressed 绘制也测文字对比度。滑块检查真实绘制，不能只测全局 token；复选框描边不用装饰分隔线颜色。
- 14种线性图标在16/18/20/28pt槽位检查含描边的边界；不把组件局部样式豁免于最终验证。

## 验证命令与边界

- `cargo test --all-targets --all-features --locked`：最终74项通过，1项写真实用户目录的测试保持 ignored；严格 Clippy、格式和 diff 检查。
- `cargo run --locked --features ui-preview --example ui_preview -- <output>`：27张合成 UI 图，用于实际组件视觉检查；不是 Windows 实机截图。
- macOS 已从最终DMG原位安装build7并抽查：左导入/右筛选、插件过滤、快捷搜索/清除、原生文件选择打开后取消、深浅主题预览、减少动效选项、取消恢复、设置快捷键和保存原设置。最终偏好字节与260个原用户文件哈希一致；未退出Cavalry。实际库截图仅留本地，公开图全部使用合成数据。
- Windows release 与测试EXE交叉构建、PE / 图标 / DPI / CRT / 归档静态检查；**不等于测试EXE已执行**。原生拖窗、GPU、多屏、任务栏缓存与安装器实机验收仍延期。
- 不退出正在编辑的 Cavalry；真实宿主退出 / 重启、完整读屏流程未验收。GitHub原生CI尚未运行，本版仍是本地候选，未发布。
