# CavalryKit 0.1.1 · build 8 元素材质 / 动效复查

本轮以用户给出的 Activo 截图和参考项目的实际样式 / 动画源码做组件级对照，保留 **左侧导入、右侧类型筛选与列表**。这是工程复查，不是审美认证；用户是否认可仍待确认。

## 参考对应到什么，而不是只换主题色

| 参考要点 | build 7 的不足 | build 8 的落实 |
|---|---|---|
| 蓝灰表面用微小明度差分层 | 灰色大壳体、强边框套框 | 蓝灰画布 / 卡片 / 悬停三级表面；右列表不再套外框，行卡用8pt留白分隔 |
| 绿色只强调关键动作与当前状态 | 浅薄荷大按钮与灰色胶囊筛选 | 6pt圆角、13pt标签、紧凑绿色按钮；细上沿光与弱投影；白字的填色保持可读，不硬抄低对比色 |
| 筛选以文字 / 细绿色下划线表示 | 多层灰色选中底板 | 单一2pt指示线，文字和命中区域不移动；反向切换从当前绘制位置接续 |
| 次要操作低干扰 | 行分隔线、图标底板和操作抢视觉 | 13pt文件名、次要元信息、弱图标底板、quiet操作；搜索只在焦点时强调边界，空搜索不显示无效清除按钮 |
| 形状先到、信息后到、最终稳定 | 多数只有短暂hover变色 | 拖入装饰轻回弹/一次环形反馈；筛选内容显现；弹窗表面和正文分阶段入场，设置分类独立显现 |

参考项目检查范围：`App.axaml` 的交互状态、`SettingsWindow.axaml` 的比例、`HudAnimations.cs` 的阶段 / easing、`HudWindow.axaml.cs` 的取消与最终状态。仅借鉴原则，没有执行其软件或复制素材；没有把读取源码说成参考软件原生实测。不复制其6秒HUD全流程，也不引入无关账户 / 数据采集。

## 交互时序与安全

- Hover / press 约180ms；筛选指示线220ms，选择被打断时平滑重定向；列表内容240ms、设置分类200ms。
- 拖入装饰340ms，约5pt上移 / 小于5%的曲线过冲、板形 / 阴影与单次环形反馈。**按钮、搜索、筛选命中区域不随之移动**；低窗口尺寸仍检查内容边界。
- 模态280ms：表面先出现，正文随后显现；位移8pt以内，绘制和实际交互区域由同一Area定位。近透明首帧禁用模态动作，背景动作从首帧起禁用，避免透点。
- 所有动画到达最终状态后停止请求重绘；无空闲波纹、持续弹跳或隐藏循环。减少动效直接使用最终状态，不让旧时间线继续残留。
- 全部退出 / 取消仍立即执行；本轮不宣称实现了模态退出动画。真实宿主退出 / 重启逻辑没有改动。
- 8秒示例由实际 Rust / egui 组件、合成库和固定输入序列渲染成240帧；包含演示指针。它不是HTML视觉稿，也不是Windows原生录像。

## 尼尔森十项逐项结论

| 原则 | 结论 | 证据 / 边界 |
|---|---|---|
| 系统状态可见 | 工程检查通过 | 宿主文字+状态点、拖入反馈、忙碌/队列文字、独立结果保留；转场不是完成进度条，不伪造任务状态。 |
| 符合用户语言与习惯 | 工程检查通过 | 锁定左导入/右筛选位置，文件名保持原样；四语言/占位符/区域字体检查。 |
| 用户控制与自由 | 工程检查通过 | 动画可被新选择打断，减少动效立即到终态；设置取消、Esc、稍后保留，不延迟执行取消。 |
| 一致性与标准 | 工程检查通过 | 主次动作统一尺寸/材质，小复选框仍用3pt圆角；单个选中指示线，普通模态动作组右对齐。 |
| 错误预防 | 工程检查通过 | 新增模态首帧阻挡“按下背景按钮后打开模态再释放”的回归；近透明内容不可激活，危险确认和回滚逻辑不变。 |
| 识别优于回忆 | 工程检查通过 | 入口文字、筛选、搜索、动作提示和可见焦点保留；只删除重复和无用装饰，不以极简隐藏安全反馈。 |
| 灵活性与效率 | 工程检查通过 | 万条虚拟列表/缓存/分页保留；动效结束后无持续重绘；鼠标、键盘激活和禁用态回归。不冒称GPU端到端或Windows拖窗性能已实测。 |
| 美观与简约 | 已落实对照项，审美待确认 | 深浅色、材质、字体层级和留白统一；静态预览和中间动画帧人工检查。不能用测试通过替代用户审美确认。 |
| 错误诊断与恢复 | 工程检查通过 | 成功/跳过/失败分开，长错误滚动，取消仍保留前面的错误；动画不隐藏错误或把写入假称为撤销。 |
| 帮助与文档 | 工程检查通过 | 格式提示、About、双语说明、操作与平台限制同步；真实用户库和工程信息不用于公开截图。 |

## 尺寸、间距和颜色检查

- 4pt紧密关系、8pt行卡/同组、16pt卡片内边距、24pt两列/明显分组；窄逻辑窗口列间隔16pt。标题/字体/描边/光学位移不是间距token。
- 固定36pt动作命中高度、40pt搜索、64pt虚拟行步长（56pt卡片+8pt间隔）；8pt卡片、6pt按钮、3pt小复选框。
- 四语言、深/浅/自定义、720×496 / 900×620 / 1120×760、忙碌状态、四设置页与长模态；缩放与模拟DPI的动作可达检查继续执行。
- 正文/状态文本跨实际表面至少4.5:1；主按钮实际hover/pressed填色也检查，滑块测最终绘制。装饰分隔线不冒充控件的可读性边界。
- 指示线无灰色底板、单层主按钮壳体、14种图标笔画边界、模态首帧安全、动画取消/重开、减少动效和稳态不重绘都有专门回归。
