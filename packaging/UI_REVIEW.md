# CavalryKit 0.1.1 / build 9 · 原生交互与热区复查

按项目开发skill v0.1.4执行；保留用户指定的左导入 / 右筛选布局。此前build8的合成GIF不能替代用户真机反馈，本轮先诊断实际输入再调整设计。审美认可仍待用户确认。

## 查到什么 / 没有证明什么

- 运行路径/版本/偏好已核对：用户没有开启减少动效。build8同处理器的原生trace-only诊断中，真实坐标点击筛选在约217ms内有27个更新样本、25个中间值；没有强制持续重绘。因此没有证据把问题概括为“macOS完全不画动画”。
- 实际设计缺口：大导入卡片普通hover不反馈且空白不可点，GIF触发的却是模拟文件drag；搜索可见图标/留白也不完整对应输入热区。短小的装饰反馈与用户日常操作缺乏对应。
- 本轮参考实际已运行的Endfield Charge Plus For MacOS 0.1.2：设置/方案分组、标签与控件关系、状态明确；触发本地系统盘预览，但独立HUD未由当前工具返回。其完整HUD时序只按macOS源码分析，不冒称捕获了参考应用全部动画。

## 重新设计的交互约定

| 元素 | 可见样式 / 热区 / 反馈 |
|---|---|
| 左导入卡片 | 图标→说明→主动作聚合，底部保留安全提示。**整个卡片一个Button响应**，视觉按钮不再嵌套抢事件；空白点击与键盘Enter均可打开选择器。 |
| 普通悬停 | 卡片表面、侧边强调线、图标底板/位置有明确短过渡，不要求真的拖入文件才有反馈。命中区域固定。 |
| 文件拖入 | 与普通hover分开的状态通道；正常撤回不导入，真正drop才进原后台队列。不可用/模态后面的动作不能触发。 |
| 搜索 | 44pt高，图标/外缘/留白点击均聚焦输入；清除40pt独立目标，空输入时隐藏。背景热区不制造额外键盘停靠点。 |
| 类型与行操作 | 普通动作40pt高，筛选等宽文字/指示线；显示与卸载之间16pt间距、独立热区，不把删除扩大到整行。 |
| 设置开关 | 标签和轨道共用一个48pt起的整行目标，状态可访问；轨道/滑块过渡，标签区也能操作。 |
| 其他 | 保留深浅独立表面、主次动作、焦点、状态文字、4/8/16/24间距和右对齐模态动作；不重复迁移用户的功能位置。 |

尺寸是此鼠标/触控板桌面工具的设计约定，不把网页CSS像素或移动端目标标准套成桌面认证。

## 尼尔森十项原则

| 原则 | 状态 | 本轮证据 / 边界 |
|---|---|---|
| 系统状态可见 | 已测范围通过 | hover/press/selected/busy可分辨；卡片安全状态保留文字与可访问标签，成功/失败仍独立反馈。 |
| 符合现实与用户语言 | 已测范围通过 | 左导入/右筛选不变，原文件名不改；卡片视觉形状与点击行为一致，不再靠猜测小按钮。 |
| 用户控制与自由 | 已测范围通过 | 原生文件选择取消、设置取消/减少动效/Esc保留；动画可重定向且不延迟取消。 |
| 一致性与标准 | 已测范围通过 | 相同动作40pt、搜索44、整行开关48+；鼠标、键盘、焦点和原生状态有回归，热区不等于图标尺寸。 |
| 错误预防 | 已测范围通过 | 危险与安全操作有16pt分隔，边界不相交；模态首帧阻挡背景，卡片单次响应防止重复选择器。 |
| 识别优于回忆 | 已测范围通过 | 常用入口与文字可见，整块卡片/开关标签可用，搜索装饰点按可进入输入；不只有gif演示时才发现触发条件。 |
| 灵活性与效率 | 已测范围通过 | 输入路径缩短、搜索/筛选/大列表缓存不变，长空闲后hover平滑，稳定状态不请求动画重绘。 |
| 美观与简约 | 已落实，审美待确认 | 信息聚合、卡片与设置行一致；去掉仅演示用的公开旧GIF，不以静态截图代替可用性结论。 |
| 错误诊断与恢复 | 已测范围通过 | 先核对原生事件链/设置/时间，不先认定用户没开开关；后台回滚、错误可展开和取消保留失败不变。 |
| 帮助与文档 | 已测范围通过 | 验证文档新增限时opt-in诊断，区分离屏/trace-only/帧采集，保留平台/隐私限制。 |

## 回归与原生证据

- **86项自动测试通过，1项写真实用户目录的测试ignored**；严格Clippy、fmt、diff检查。
- 新增整块卡片四角/按钮同目标、列间空白不误触、搜索装饰与清除分离、长空闲后普通hover、行操作最小尺寸/危险间隔、开关标签与轨道单次切换、卡片键盘与不可用状态等回归。
- 保留四语言/深浅/自定义、三档尺寸、缩放/模拟DPI、长内容、万条列表、动画重定向/终态与模态首帧保护测试。
- 原生trace-only使用真实坐标输入，不强制每帧渲染；另一次诊断采得**35张原生窗口渲染帧**，见卡片hover、筛选和设置过渡。不是生成固定30fps序列；截图采集本身会影响帧时间，不能当性能基准。
- 已原生确认：卡片空白打开文件选择→取消、搜索图标点击后输入、设置整行标签切换开关、减少动效和浅色预览、取消恢复。相关真实库截图仅私有保存。
- 最终build9已从签名DMG原位安装：45项编译/嵌入输入、签名/CRC、Windows资源/归档与已安装字节核对通过；原生正常启动和布局已检查。进一步最终包鼠标抽查因用户同时检测而停止，不把未完成动作标成通过；此前同UI源码的诊断原生动作保留其准确证据层次。
- Windows只交叉构建/静态检查，EXE没有实机执行；宿主Cavalry未退出，完整读屏与混合DPI仍未验证。用户检测期间的偏好变化保留，不以恢复测试基线覆盖用户的新选择。
