# CavalryKit 0.1.1 · UI / 可用性复查

本记录对应 **0.1.1 / macOS build 6** 的参考图驱动重设计，是工程启发式复查，不是第三方认证，也不替代真实用户测试。视觉方向结合参考图的紧凑侧栏、分层背景、轻分隔线和 Cavalry 深灰 / 绿色；4/8/16/24 间距来自本项目设计约定，不归因于尼尔森原则。

## 设计结果与本轮范围

- 全宽品牌 / 宿主状态栏，208pt 分类侧栏；主区使用横向导入卡片、独立搜索和轻分隔列表，减少大边框和重复强调。
- 搜索提示改为「搜索插件或脚本名称」；中文 UI 改用 SC 字形，日 / 韩分别选择 JP / KR 字形。内嵌 Regular / Medium 字重，保留 Roboto 拉丁字体和用户文件名的系统字体回退。
- 导入说明按内容换行，不再放进固定高度文本槽；忙碌 / 队列信息与结果模态框各自独立。
- 设置拆分为通用、界面配色、安装行为、Cavalry 四页；配色卡片可预览，保存 / 取消 / 恢复默认仍使用草稿，不擅改宿主设置。
- 原有后台任务、冲突安全默认、废纸篓卸载确认、安全重启、平台图标和固定路径升级流程保留。

## 间距、尺寸与边界

- **4pt**：紧密文字关系、导航项间距；**8pt**：同组控件 / 弹窗按钮之间、图标文字关系。
- **16pt**：导入 / 列表 / 设置内容内边距、搜索与导入之间；**24pt**：主区内边距、设置分类与内容分隔、模态内边距与明显分组。
- 控件 36pt；搜索框 / 侧栏项 40pt；列表行 64pt；品牌栏 64pt。字号、圆角、笔画和图标光学偏移不强行套用间距数值。
- 默认原生窗口 1120×760、最小 900×620；125% 界面缩放对应更小的逻辑内容。离屏测试包含 720×496、900×620、1120×760；侧栏 / 设置内容不足时独立滚动，底部保存 / 取消仍可达。
- 界面缩放 90 / 100 / 110 / 125%，另用 100 / 125 / 150 / 200% 原生 DPI 输入验证模态可达区域；这不是实际多显示器验收。
- 几何断言覆盖标题 / 状态互不重叠、导入说明包含于卡片内、搜索 / 列表不越界、四个设置页正文与底部动作不重叠、模态按钮组右对齐。
- 搜索清除按钮用独立 36pt 命中区域；行操作按本地化文字的实际宽度留位，滚动条单独预留空间；额外从实际绘制图形检查滑块与背景至少 3:1，而不只检查全局 palette。
- 极端自定义配色下，正文 / 次要 / 状态文字跨实际表面检查至少 4.5:1，对比度不足时调整文字；强调按钮自动黑 / 白字，焦点有描边，状态不只靠颜色。

## 收尾复查发现与修复

列表曾为避免亮色滑块而局部压暗控件前景，导致实际默认滑块对比度约 1.92:1，尽管全局颜色 token 的测试通过。现移除该覆盖，保留窄滑块尺寸和全局透明度；新增实际绘制形状的深 / 浅 / 自定义主题回归，目标至少 3:1。修复前测试失败、修复后通过，最终候选内部构建号由 5 提升至 6。

## 回归及证据层次

1. **macOS 自动执行**：`cargo test --all-targets --all-features --locked`，68 项通过、1 项 ignored；ignored 测试会写真实用户目录，未执行。严格 Clippy、格式及 diff 检查通过。
2. **实际组件离屏渲染**：`cargo run --locked --features ui-preview --example ui_preview -- <output-directory>`，21 个四语言 / 小尺寸 / 配色 / 模态场景。README 中两张截图使用合成库，不包含用户的实际插件或脚本名。
3. **macOS 原生交互**：已安装 build 6；中文主界面 / 配色、英文预览、125% 缩放、四设置页导航、取消恢复、搜索 / 无结果 / 清除、卸载确认后 Esc 取消、原生应用路径选择器打开 / 取消已检查。偏好和原用户文件的哈希一致。
4. **Windows 构建与静态检查**：release 与全部测试 EXE 交叉构建；PE / 图标 / 版本 / DPI / DLL 依赖及 ZIP 成员检查。测试 EXE **未在 Windows 执行**。
5. **发布状态**：本地候选，尚未新建 0.1.1 Release；远程工作流尚未运行，不将准备好 CI 文件写成 CI 通过。

## 剩余未验证 / 不适用范围

- Windows 原生拖窗、GPU / 旧显卡、多屏 / 混合 DPI、任务栏缓存及固定路径升级的人工验收仍延期；交叉编译不能替代这些体验检查。
- 没有请求关闭 / 重启用户当前的 Cavalry；原生平台接口仅完成构建，取消、超时、多实例等状态机分支使用 fake backend。
- 原生 VoiceOver / Narrator 的完整读屏流程未验收；本次检查无障碍标签、焦点和相关组件行为，不宣称完整无障碍合规。
- 整套颜色 / 字体 / 间距没有第三方认证；审美满意度仍需用户确认，不能承诺所有环境绝对无 bug 或零卡顿。
